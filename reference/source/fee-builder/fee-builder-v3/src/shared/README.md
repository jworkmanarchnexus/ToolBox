# Shared Toolbox design language

These files are the visual foundation every Toolbox tool should share. They were taken **unchanged** from the Toolbox Scheduler (the first Toolbox module) so Fee Builder and the Scheduler render from the same tokens and components.

| File | What it is | Provenance |
|---|---|---|
| `toolbox-fonts.css` | Lato 400/700 and Roboto Condensed 400/700 as embedded woff2 (SIL Open Font License 1.1) | Scheduler lines "Generated by tools/gen-assets.py" |
| `toolbox-base.css` | Design tokens (brand palette, surfaces, lines, text, states, spacing, radii, shadows, light and dark) and shared components (buttons, `.seg`, form controls, `.chip`, menus, banners, dialogs, toast), plus the shell (side nav, page header `.phead` / `.ptitle` / `.crumbs`) | Scheduler, "Arch Nexus design tokens" through `.ptitle` |
| `toolbox-shell-narrow.css` | The side bar becoming a drawer on narrow screens | Scheduler's responsive block, with its Scheduler-only list rules removed |
| `toolbox-logo.dataurl` | The approved Arch Nexus logo (PNG, 243 × 300) | Scheduler `LOGO` constant |

## Rules a tool follows

1. Never redefine a token. A tool's own CSS may add aliases (`--blue: var(--nx-blue)`) and tool-specific components, nothing else.
2. The page is: side bar, breadcrumbs, a `.ptitle` row (title left, actions right, a hairline under it), then content. The tool's name is the title in `h1.brand` (Nexus Blue, uppercase) on its landing page; a record's name is the title (plain, dark) once one is open.
3. One primary button per screen (`.btn.primary`), top right. Everything else is a plain `.btn`, `.btn.quiet`, or `.ib` icon button. Sentence case labels.
4. Controls are 32 px (28 px inside dense tables), 4 px radius, 1 px `--line-strong` border, a `--focus` ring.
5. Section headings are condensed uppercase with a hairline above (`.section-h` in the Scheduler, `.sec > header` in Fee Builder). Table headers are condensed uppercase `--text-2`.
6. Selected or current items use `--accent-soft` with an `--nx-blue` mark. Nexus Blue is for marks, focus, and the page title; blue **text** is `--accent-text`.
7. Status uses banners (tinted band, colored left rule) and chips, one meaning per color: info, warn (orange), ok (green), crit (red, functional, not in the brand palette).
8. Light and dark come from the same token names; never hard-code a color in a component.

## Differences between Fee Builder and the Scheduler (deliberate)

- **Scrolling.** The Scheduler scrolls an inner pane inside a 100vh shell; Fee Builder lets the document scroll and keeps the side bar sticky. Same look; this keeps the app's focus and scroll handling simple. A tool with a timeline (the Scheduler) needs the inner pane.
- **Editable fields in tables** use the shared bordered control at 28 px, with calculated values as plain text. The Scheduler's grid editing may differ.
- **Tool registry.** The Scheduler's `TOOLBOX_MODULES` lists only itself. Fee Builder's `TOOLBOX_TOOLS` (in `views.js`) lists Fee Builder, Scheduler, and Minutes, the other two as links that open in a new tab. When the tools live behind one origin, both should read the same registry.

## Not yet unified

- **Nexus Minutes** has its own token set (`--paper`, `--ink`, `--tint`) and no side bar. It needs the same treatment Fee Builder just received.
- The Scheduler and Fee Builder each carry their own copy of these files. The next step is one shared stylesheet served from the Toolbox, so a token change lands everywhere at once.
